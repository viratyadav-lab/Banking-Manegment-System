Banking Management System in C

A console-based Banking Management System developed in C to practice programming fundamentals through a practical project.

Features

* Create a bank account
* Display account details
* Deposit money
* Withdraw money
* Check account balance
* Update account holder details
* View transaction history
* Menu-driven interface

Concepts Used

* Functions
* Pointers
* Arrays
* Global variables
* Conditional statements
* Loops
* User input and output
* Basic transaction management

How to Run

Prerequisites

* A C compiler, such as GCC
* A terminal or code editor

Compile

gcc createaccount.c -o banking

Run on macOS or Linux

./banking

Learning Objective

This project was built to strengthen my understanding of C programming by implementing basic banking operations, handling user input, and organizing a program using functions.

Future Improvements

* Support multiple bank accounts
